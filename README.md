# Rita Monteiro — Psicologia

Website institucional em português de Portugal, desenvolvido com React, TypeScript e Vite.

## Desenvolvimento local

- `npm install`
- `npm run dev`
- `npm run build`

## Estado atual

Primeira versão frontend com homepage, apresentação, serviços, processo de contacto, formulário demonstrativo, artigos de rascunho e área de recursos.

## Antes de publicar

- Validar textos e acrescentar biografia, formação, experiência e cédula profissional confirmadas.
- Inserir contactos reais e configurar WhatsApp.
- Ligar o formulário a um serviço seguro de receção de pedidos.
- Rever privacidade, cookies e textos legais.
- Criar catálogo, preços, condições de venda e checkout antes de ativar a loja.

O formulário atual é demonstrativo: não envia nem armazena dados. Não inserir informação clínica ou dados sensíveis.
